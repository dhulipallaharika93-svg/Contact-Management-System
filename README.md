# Contact Management System

A Python-based Contact Management System for managing contacts.

## Features

- Add Contact
- View Contacts
- Search Contact
- Update Contact
- Delete Contact
- JSON File Storage

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

Run the following command:

python contact_management.py
